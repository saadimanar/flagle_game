# Flagle 🌍

A simple and fun game where you guess the country based on its flag.

👉 Play it here: https://flagle-game.vercel.app/

## About

Flagle is a lightweight web game built with React where each round shows a random flag and you have a limited number of attempts to guess the correct country.

I built this project to focus on clean UI, smooth user experience, and integrating real-world infrastructure like AWS S3 for asset delivery.

## Features

- 🌐 Random flag each round  
- 🎯 Limited attempts to guess correctly  
- ⚡ Fast loading using AWS S3 for flag assets  
- 🎨 Clean and responsive UI  
- 🚀 Deployed on Vercel  

## Tech Stack

- React + Vite  
- Tailwind CSS  
- AWS S3 (for hosting flag SVGs)  
- Vercel (deployment)

## Notes

This project focuses on simplicity, performance, and a polished user experience rather than complexity.
